# Silvia Tcherassi Collection

This is a single-page e-commerce website for the "Silvia Tcherassi" brand, showcasing various collections of clothing and accessories.

[View the live site]([https://anselmem.github.io/Silvia-rassi-Collection/])

## Technologies Used

*   HTML
*   Tailwind CSS
*   JavaScript

## Features

*   **Single-page application (SPA) design:** The website content is loaded dynamically without requiring page reloads.
*   **Product browsing:** Users can browse products by various categories, including:
    *   All Collections
    *   Handbags
    *   Dresses
    *   Accessories
*   **Product "Quick View":** A modal window allows users to quickly view product details without leaving the main page.
*   **Shopping cart functionality:** Users can add items to their shopping cart, view the cart contents, and see the subtotal.
*   **Responsive design:** The website is designed to be mobile-friendly with a responsive navigation menu.

## How to Run Locally

1.  Clone this repository to your local machine.
2.  Open the `index.html` file in your web browser.
